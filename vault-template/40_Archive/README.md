# 40_Archive

La cartella **Archive** contiene il materiale storico, progetti conclusi e documentazione deprecata del vault.

## Criteri di archiviazione
- **Progetti terminati:** Quando un progetto in `10_Projects/` raggiunge lo stato `completed` o `cancelled`, viene spostato qui.
- **SOP e memorie superate:** Memorie procedurali o decisionali che sono state sostituite da versioni successive (`status: superseded` o `status: archived`).
- **Log di sprint passati:** Report di sprint o sessioni di lavoro non più rilevanti per il contesto attivo.

## Utilità per la sintesi del vault
Il comando `brain_archive_memories` utilizza questo spazio per archiviare memorie obsolete e non più rilevanti, migliorando le performance delle ricerche attive e consentendo il recupero storico quando necessario.

## Proprietà
I file archiviati rimangono leggibili e indicizzabili per consultazioni storiche o audit, ma non concorrono alle priorità attive delle ricerche di contesto operativo quotidiano.
