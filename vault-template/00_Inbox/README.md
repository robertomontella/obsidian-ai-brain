# 00_Inbox

Benvenuto nella casella di cattura rapida (**Inbox**) del tuo AI-BRAIN.

## Scopo della cartella
Questa cartella funge da memoria di lavoro immediata per:
- Cattura rapida di idee, note grezze e snippet di codice
- Appunti transitori raccolti durante sessioni operative degli agenti AI
- Note in attesa di essere smistate secondo il metodo PARA

## Flusso di lavoro consigliato
1. **Cattura rapida:** Scrivi liberamente le tue note in questo spazio.
2. **Revisione periodica:** Durante i check-in o la chiusura di sprint, sposta le note nelle destinazioni appropriate:
   - `10_Projects/` se relative a un progetto attivo con scadenza.
   - `20_Areas/` se pertinenti a una sfera di responsabilità continuativa.
   - `30_Resources/` se materiale di riferimento, guide o cheat sheet.
   - `50_Memory/` se decisioni architetturali, principi stabili o SOP per agenti.
   - `40_Archive/` se non più attuali o completate.
